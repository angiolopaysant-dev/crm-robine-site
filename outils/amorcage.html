Amorçage du CRM (une seule fois)

À quoi sert cette page

Elle fonctionne entièrement dans ton navigateur, sans rien envoyer sur Internet. Elle crée la clé de données (à mettre dans le secret GitHub DATA_KEY) et ton compte administrateur (le fichier _site/users.json à déposer dans le dépôt privé). Ensuite, les autres comptes se gèrent depuis la page Administration du site.

1. Clé de données

2. Ton compte administrateur

C’est prêt. Copie les deux éléments ci-dessous, puis ferme cette page.

Secret GitHub DATA_KEY

Dépôt crm-robine → Settings → Secrets and variables → Actions → New repository secret, nom DATA_KEY. Garde aussi une copie dans ton gestionnaire de mots de passe : sans elle, plus personne ne peut se connecter.

Fichier _site/users.json

Dans le dépôt crm-robine : Add file → Create new file, nom _site/users.json, colle ce contenu, Commit. Il ne contient que des données chiffrées.
